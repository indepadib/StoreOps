# Strix CRM security review

Manual, approved source-only scan. Do not scan storeops.ma, Dynamics, customer data, production credentials, or production database. The copied files are a bounded code-only scope, not the entire application, and the model provider may receive source snippets. Obtain organizational authorization for that provider and inspect the scope for embedded secrets before enabling the environment. Configure dedicated STRIX_LLM and STRIX_LLM_API_KEY as GitHub environment secrets (never reuse Dynamics or production credentials). Configure required reviewers for the strix-security-review environment. Run on main after review, with the approval input checked. The CLI is pinned to v1.5.2 with a USD 5 model budget and 25-minute job limit; this is not a guarantee of total billing. No automatic scans or production testing. Review the report in private, fix verified findings, add regression tests, and rerun. Exit 0 alone is not proof of complete coverage; inspect run status and budget.
